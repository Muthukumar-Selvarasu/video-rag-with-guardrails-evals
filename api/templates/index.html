If ungrounded or hallucinated, the response is replaced with a safe fallback notice.

Why runtime guardrails are non-negotiable in production AI systems:
🛡️ 1. Input Guardrail Pre-LLM
The First Line of Defense: Intercepts adversarial prompts before consuming tokens or invoking cloud APIs.
• Injection Patterns: ignore previous, system prompt, jailbreak, DAN mode, override instructions.
• Domain Classifier: Enforces topic relevance to Claude Code, terminal workflows, and AI pair-programming.
• Cost Impact: Blocks attacks in < 5ms with $0 LLM invocation cost.
🎯 2. Output Guardrail Post-LLM
Truth & Security Verification: Validates what the LLM generated before letting the user see it.
• Secret Leak Scanner: Regex scanning for API keys (sk-, AIza), environment variables, and credential dumps.
• Lexical Faithfulness: Jaccard overlap between answer tokens and retrieved video transcript context (≥ 0.15 threshold).
• Refusal Bypass: Legitimate "not found in course" refusals pass cleanly without penalization.
🧪 3. Automated Evaluations CI / Pytest
Rigorous CI/CD Test Suite: Tested and scored using Ragas-compatible evaluation methodology.
• Context Precision: Measures whether relevant video chunks rank at top positions.
• Faithfulness: Verifies answers are 100% derived from source cues.
• Injection Defense: 25 automated unit & integration tests passing in ~9.8s.
How 9.2 hours of video become instant, zero-database serverless search:
🎙️
1. Whisper Transcription
5 video sessions (~9.2 hours) transcribed with high-accuracy timestamps into raw VTT and JSON cue objects via transcribe_all.py.
✂️
2. Cue Boundary Chunking
chunker.py groups contiguous sentences into 200-400 token semantic segments while strictly preserving start and end timestamps.
🧬
3. Vector Preindexing
preindexer.py embeds all 691 chunks using Gemini 768-D vectors and compiles them into a single portable preindexed_embeddings.json file.
⚡
4. Serverless In-Memory Search
Vercel loads the JSON into Python memory on cold start. Cosine similarity executes via pure math in ~15ms with zero database costs or maintenance.
